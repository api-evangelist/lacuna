## APIs

- **Lacuna Music API** — Paid REST music-generation API (Pro tier and above) using lyr_live_ API keys, HMAC-signed webhooks, and an OpenAI-style error envelope. SDK-mediated; no public machine-readable contract. Accompanied by an Agent Skill and an advertised llms.txt. (`https://www.lacuna.fm`)

> REST Music API is real but SDK-mediated: no independently documented raw HTTP base URL (declared baseURL is www.lacuna.fm) and no public machine-readable contract (no OpenAPI/AsyncAPI/GraphQL/Postman). API access requires Pro plan+, uses lyr_live_ keys, 60 rpm rate limit, and HMAC-SHA256 signed webhooks (job.completed/job.failed via x-lacuna-signature). The MCP server (lacuna-mcp) is a LOCAL stdio server run via 'npx lacuna-mcp' — NOT a hosted public MCP endpoint, so it is not cataloged as an MCP property. The lacuna-music Agent Skill (SKILL.md standard, installable via 'npx skills add JOYLINK-LTD/lacuna-toolkit') and the llms.txt make this agent-native. Note: llms.txt and /.well-known/api-catalog are advertised but were not independently fetch-verified this session.
